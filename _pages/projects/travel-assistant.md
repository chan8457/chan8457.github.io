## 프로젝트 개요

최근 채용 공고들을 보면서 **LLM 활용 능력**이 데이터 직무에서 점점 필수 역량이 되고 있다는 걸 체감했습니다.   
단순히 “AI를 써본 적 있다” 수준이 아니라,  
**실제 데이터를 기반으로 LLM이 어떻게 문제를 해결할 수 있는지 구조적으로 경험해보고 싶었습니다.**

평소 저는 여행을 갈 때마다  
“어디를 가야 하지?”,  
“이번엔 바다를 볼까? 아니면 조용한 카페가 좋을까?”  
이런 고민에 시간을 많이 쓰곤 했습니다.  

그래서 이 프로젝트의 방향을  
**‘내가 실제로 겪는 여행지 선택 피로를 줄이는 LLM 프로젝트’**로 정의했습니다.

이를 위해 카카오맵, 트리플, 마이리얼트립 등 다양한 여행·맛집 플랫폼에서  
여행지 정보·카테고리·위도/경도·리뷰 텍스트를 직접 수집한 뒤,

사용자가  
> “오늘은 바다 보러 가고 싶고, 너무 붐비지 않았으면 좋겠어”  

처럼 자연어로 입력하면,

LLM이 이 문장을 **의도·필터·선호 태그**로 구조화하고,  
제가 수집한 실제 장소 데이터를 기반으로  
**여행지 + 주변 관광지 + 식당 + 간단한 코스까지 자동으로 추천하는 서비스**를 설계했습니다.

이 프로젝트를 통해 다음 세 가지 목표를 달성하고자 합니다.

1. **데이터 수집·정제·저장까지 이어지는 여행 데이터 파이프라인 구축**  
2. **LLM을 활용한 자연어 → 구조화된 조건(의도 파싱) 변환**  
3. **여행지 추천 알고리즘 + LLM 기반 결과 설명 생성 기능 구현**
