## 프로젝트 개요

광고 운영 업무를 수행하며 반복적으로 발생하는 **소재 제작 비효율**, **성과 저조 고객사 확인 지연**, **유료 광고 상품 운영 비용 관리의 어려움**을 개선하기 위해 진행한 실무 기반 프로젝트입니다.

실제 회사 데이터는 보안상 공개할 수 없기 때문에, 동일한 업무 구조를 재현한 **샘플 데이터**를 생성하고 Streamlit 기반 대시보드를 구현하여 광고 운영 성과를 모니터링하는 흐름을 구성했습니다.

본 프로젝트의 핵심은 광고비를 단순히 많이 사용하는 것이 아니라, 고객사별 성과 흐름을 확인하며 **지원자 수는 유지하거나 늘리고, 지원당 비용은 낮추는 운영 구조를 설계하는 것**입니다.

| 항목 | 내용 |
|------|------|
| 기간 | 2025.10 ~ 2026.04 |
| 유형 | 실무 기반 업무 개선 및 샘플 데이터 재현 프로젝트 |
| 역할 | 광고 운영 데이터 구조 설계, 성과 지표 정의, 샘플 데이터 생성, Streamlit 대시보드 구현 |
| 사용 기술 | Python, Pandas, Streamlit, Midjourney, ChatGPT |
| 핵심 목표 | 광고비 대비 지원자 수 개선, 성과 저조 고객사 조기 파악, 반복 운영 업무 효율화 |

## 문제 정의

광고 운영 과정에서 가장 큰 문제는 단순히 광고 성과가 낮다는 점이 아니라, **성과가 낮아지는 흐름을 빠르게 발견하고 대응하기 어렵다는 점**이었습니다.

특히 여러 고객사를 동시에 관리하는 상황에서는 각 고객사의 지원 수, 클릭률, 광고비, 유료상품 사용량을 개별적으로 확인해야 했기 때문에 다음과 같은 문제가 발생했습니다.

- 고객사별 지원자 수와 클릭률 변화를 수동으로 확인해야 함
- 광고비를 많이 사용해도 실제 지원자 수 증가로 이어지지 않는 경우가 있음
- 성과 저조 고객사를 빠르게 파악하기 어려움
- 유료상품을 줄였을 때 성과가 유지되는지 확인하기 어려움
- 소재 변경, 문구 수정, 유료상품 조정의 효과를 정량적으로 비교하기 어려움

따라서 본 프로젝트는 광고 운영 데이터를 기반으로 **고객사별 광고비, 지원자 수, 클릭률, 지원당 비용을 함께 확인할 수 있는 구조**를 만드는 데 집중했습니다.

## 주요 용어 설명

채용 광고 운영에서는 단순히 지원자 수만 보는 것이 아니라, 지원 이후 실제 진행 가능한 인원까지 함께 확인해야 합니다. 이를 위해 본 프로젝트에서는 다음과 같은 기준으로 지표를 정의했습니다.

| 용어 | 설명 |
|------|------|
| 지원자 수 | 공고를 보고 지원한 전체 인원 |
| 가용 인원 | 연락 가능하거나 조건이 맞아 실제 면접 안내가 가능한 지원자 |
| 비가용 인원 | 연락 불가, 조건 불일치, 중복 지원 등으로 실제 진행이 어려운 지원자 |
| 면접 참석 수 | 면접 안내 이후 실제 면접에 참석한 인원 |
| CTR | 광고 노출 대비 클릭 비율 |
| 지원 전환율 | 클릭 이후 실제 지원으로 이어진 비율 |
| 지원당 비용 | 광고비를 지원자 수로 나눈 값 |
| 광고비 효율 | 동일한 광고비로 얼마나 많은 지원자를 확보했는지 보는 지표 |

이 기준을 통해 단순히 “지원자가 많다/적다”가 아니라, **지원 이후 실제 채용 절차로 이어질 수 있는 인원이 얼마나 되는지**까지 함께 확인할 수 있도록 했습니다.

## 광고비 산정 기준

실제 운영 환경에서는 고객사별로 여러 채용광고 유료상품을 조합하여 운영했습니다.

다만 본 포트폴리오에서는 회사 내부 정책 및 상품 단가를 직접 공개하지 않고, 고객사별 유료상품 사용량을 기반으로 광고비 지표를 산정했습니다.

광고비는 다음 요소를 반영해 계산했습니다.

| 기준 | 설명 |
|------|------|
| 상품 유형 | 노출 효과가 큰 상품과 일반 유료상품을 구분 |
| 상품 사용 수 | 고객사별로 사용한 유료상품 개수 |
| 운영 기간 | 특정 기간 동안 사용된 광고 상품 기준 |
| 광고비 지표 | 실제 단가 대신 샘플 데이터용 광고비 컬럼으로 변환 |

대시보드에서는 광고비 자체보다 **광고비 대비 지원자 수**, **지원당 비용**, **1만원당 지원자 수**를 중심으로 효율을 판단했습니다.

---

## 핵심 지표 설계

광고 운영 성과를 판단하기 위해 다음 지표를 사용했습니다.

| 지표 | 의미 |
|------|------|
| 광고비 | 고객사별 유료 광고 상품 운영 비용 |
| 노출 수 | 광고가 사용자에게 노출된 횟수 |
| 클릭 수 | 광고를 클릭한 횟수 |
| CTR | 노출 대비 클릭 비율 |
| 지원자 수 | 광고를 통해 유입된 전체 지원자 수 |
| 가용 인원 수 | 실제 면접 안내가 가능한 지원자 수 |
| 비가용 인원 수 | 실제 진행이 어려운 지원자 수 |
| 면접 참석 수 | 실제 면접에 참석한 인원 |
| 지원 전환율 | 클릭 수 대비 지원자 수 |
| 지원당 비용 | 지원자 1명을 확보하는 데 사용된 비용 |
| 1만원당 지원자 수 | 광고비 대비 지원 효율을 보기 위한 지표 |

이 중 가장 중요하게 본 지표는 **지원당 비용**과 **1만원당 지원자 수**입니다.

광고비를 줄이는 것만으로는 성과 개선이라고 보기 어렵기 때문에, 광고비를 줄이면서도 지원자 수와 가용 인원 수가 유지되는지를 함께 확인했습니다.

## 대시보드 구현

Streamlit을 활용하여 고객사별 광고 성과를 확인할 수 있는 샘플 대시보드를 구현했습니다.

![광고 운영 성과 대시보드](/assets/images/ai-ad-dashboard-sample.png)

대시보드에서는 다음 항목을 확인할 수 있도록 구성했습니다.

- 고객사별 총 광고비
- 고객사별 지원자 수
- 고객사별 가용 인원 수
- 고객사별 비가용 인원 수
- 일자별 클릭률 변화
- 일자별 광고비 변화
- 지원당 비용 변화
- 1만원당 지원자 수
- 고객사별 효율 상태 분류

이를 통해 광고비를 줄였을 때 지원자 수가 함께 감소하는지, 또는 광고비를 줄여도 효율이 유지되는지를 확인할 수 있도록 설계했습니다.

## 주요 수행 내용

### 1️⃣ 샘플 데이터 생성

실제 회사 데이터는 공개하지 않고, 광고 운영 구조를 반영한 샘플 데이터를 생성했습니다.

샘플 데이터에는 다음 컬럼을 포함했습니다.

| 컬럼 | 설명 |
|------|------|
| date | 광고 운영 날짜 |
| company | 고객사명 |
| optimization_phase | 운영 단계 |
| premium_product_count | 주요 유료상품 사용 수 |
| basic_product_count | 일반 유료상품 사용 수 |
| ad_spend | 광고비 |
| impressions | 노출 수 |
| clicks | 클릭 수 |
| ctr | 클릭률 |
| applicants | 지원자 수 |
| available_candidates | 가용 인원 수 |
| unavailable_candidates | 비가용 인원 수 |
| interviews | 면접 참석 수 |
| apply_rate | 지원 전환율 |
| cost_per_applicant | 지원당 비용 |
| applicants_per_10k_won | 1만원당 지원자 수 |

샘플 데이터는 초기에는 유료상품 사용량이 많은 구조로 설정하고, 이후 운영 단계가 진행될수록 일부 유료상품을 줄이면서 성과 효율이 개선되는 흐름을 반영했습니다.

---

### 2️⃣ 고객사별 광고 성과 모니터링

광고 성과를 단순 지원자 수만으로 판단하지 않고, 광고비와 클릭률을 함께 확인했습니다.

특히 다음과 같은 질문에 답할 수 있도록 대시보드를 구성했습니다.

- 어떤 고객사가 광고비 대비 지원자 수가 높은가?
- 광고비를 많이 사용했는데도 지원자 수가 낮은 고객사는 어디인가?
- 클릭률은 높지만 지원 전환율이 낮은 고객사는 어디인가?
- 지원자 수는 많지만 가용 인원 비율이 낮은 고객사는 어디인가?
- 유료상품을 줄였을 때 지원자 수가 유지되는가?
- 지원당 비용이 높은 고객사는 어디인가?

이를 통해 광고 운영자가 모든 고객사를 동일하게 확인하는 것이 아니라, **개선이 필요한 고객사부터 우선적으로 확인할 수 있는 구조**를 만들었습니다.

---

### 3️⃣ 광고비 효율 지표 설계

광고 운영에서 중요한 것은 단순히 광고비를 줄이는 것이 아니라, 광고비를 줄이더라도 지원자 수와 가용 인원이 유지되거나 증가하는지 확인하는 것입니다.

따라서 본 프로젝트에서는 다음 두 지표를 핵심 효율 지표로 정의했습니다.

| 지표 | 해석 |
|------|------|
| 지원당 비용 | 낮을수록 적은 비용으로 지원자를 확보한 것 |
| 1만원당 지원자 수 | 높을수록 같은 비용 대비 지원자를 더 많이 확보한 것 |

예를 들어 A고객사가 더 많은 광고비를 사용해 지원자 수를 많이 확보했더라도, B고객사가 더 적은 광고비로 비슷한 지원자 수를 확보했다면 B고객사의 운영 효율이 더 좋다고 판단할 수 있습니다.

---

### 4️⃣ 가용 인원 기준의 전환 품질 확인

채용 광고에서는 지원자 수가 많아도 실제 진행 가능한 인원이 적으면 성과가 좋다고 보기 어렵습니다.

따라서 본 프로젝트에서는 지원자 수뿐만 아니라 **가용 인원 수**와 **비가용 인원 수**를 함께 확인했습니다.

이를 통해 다음과 같은 문제를 구분할 수 있습니다.

| 상황 | 해석 |
|------|------|
| 지원자 수가 낮음 | 소재, 타이틀, 노출량 문제 가능성 |
| 지원자 수는 높지만 가용 인원이 낮음 | 타겟 불일치 또는 공고 조건 전달 문제 가능성 |
| 가용 인원은 있지만 면접 참석이 낮음 | 안내 방식, 일정 조율, 고객사 응대 문제 가능성 |
| 광고비는 높지만 가용 인원이 낮음 | 광고비 효율 개선 필요 |

이처럼 지원 이후의 흐름을 함께 확인하면 단순 유입량 중심이 아니라, **실제 채용 가능성 중심의 광고 운영 판단**이 가능해집니다.

---

### 5️⃣ 생성형 AI 기반 광고 소재 기획

광고 소재 제작 과정에서는 생성형 AI를 활용하여 다양한 컨셉을 빠르게 검토할 수 있는 흐름을 설계했습니다.

- 타겟별 이미지 톤앤매너 기획
- Midjourney를 활용한 광고 소재 컨셉 이미지 생성
- ChatGPT를 활용한 광고 문구 초안 작성
- 고객사 공유 멘트 및 업무 보고 문구 템플릿화
- 성과 저조 유형에 따른 소재 교체 방향 정리

생성형 AI를 단순히 이미지를 만드는 도구로 사용하는 것이 아니라, **소재 제작 리드타임을 줄이고 여러 컨셉을 빠르게 테스트하기 위한 보조 도구**로 활용했습니다.

## 주요 인사이트

### 1️⃣ 광고비를 많이 쓰는 것과 성과가 좋은 것은 다르다

유료상품을 많이 사용하면 노출 기회는 늘어날 수 있지만, 반드시 지원자 수 증가로 이어지는 것은 아닙니다.

따라서 광고 운영에서는 총 광고비보다 **지원당 비용**, **1만원당 지원자 수**, **가용 인원 비율**을 함께 확인해야 합니다.

---

### 2️⃣ 지원자 수보다 중요한 것은 실제 진행 가능한 인원이다

채용 광고에서는 지원자가 많아도 연락이 되지 않거나 조건이 맞지 않으면 실제 성과로 이어지기 어렵습니다.

따라서 단순 지원자 수보다 **가용 인원 수와 면접 참석 수까지 이어지는 흐름**을 함께 봐야 합니다.

---

### 3️⃣ 클릭률과 지원 전환율은 함께 봐야 한다

클릭률이 높다는 것은 소재가 관심을 끌었다는 의미지만, 클릭 이후 지원으로 이어지지 않는다면 공고 내용, 조건, 타겟 적합성에 문제가 있을 수 있습니다.

따라서 CTR만으로 성과를 판단하기보다, **CTR → 지원 전환율 → 가용 인원 → 면접 참석** 흐름을 함께 확인하는 것이 중요합니다.

---

### 4️⃣ 유료상품 조정은 감이 아니라 데이터 기준으로 해야 한다

기존에는 성과가 낮으면 유료상품을 추가하거나 소재를 교체하는 방식으로 대응하는 경우가 많았습니다.

하지만 고객사별 광고비와 지원자 수를 함께 보면, 어떤 고객사는 광고비를 줄여도 성과가 유지될 수 있고, 어떤 고객사는 광고비보다 소재 개선이 더 우선일 수 있습니다.

즉, 유료상품 운영은 단순 지출 확대가 아니라 **효율 지표 기반의 조정**이 필요합니다.

---

### 5️⃣ 자동화의 핵심은 판단 시간을 확보하는 것이다

광고 운영 업무를 자동화한다고 해서 모든 업무를 기계가 대신할 수 있는 것은 아닙니다.

다만 반복적인 데이터 정리, 저조 고객사 확인, 보고 문구 초안 작성 등을 자동화하면 담당자는 더 중요한 판단에 집중할 수 있습니다.

본 프로젝트에서는 자동화의 목적을 업무 대체가 아니라, **운영자가 빠르게 판단할 수 있는 환경을 만드는 것**으로 정의했습니다.

## 한계 및 개선 방향

본 프로젝트는 실제 광고 운영 경험을 바탕으로 했지만, 회사 내부 데이터와 고객사 정보 보호를 위해 실제 수치와 원본 데이터는 공개하지 않았습니다.

- 광고비 조정 전후 지원당 비용 변화 분석
- 가용 인원 비율 기반 전환 품질 분석
- 고객사별 추천 액션 자동 생성
- 실제 운영 데이터 연결을 고려한 데이터 파이프라인 설계
