## 채용 공고를 보다가 생긴 의문 🤔

요즘 데이터 분석가 채용 공고를 보다 보면  
**‘LLM 경험 우대’, ‘RAG 경험자’, ‘AI 기반 분석 이해’** 같은 문구가 정말 자주 보입니다.  
처음엔 단순한 유행어겠지 했는데, 점점 **업무 자체가 바뀌고 있다**는 느낌이 들었습니다.

그래서 “LLM이 정확히 뭘까?”,  
“데이터 분석가와 어떤 관계가 있을까?”  
제대로 공부해 보기로 했습니다.

참고 자료:  
- IBM — *What Are Large Language Models?*  
- HPE — *What is a Large Language Model?*  
- InfoWorld — *How to run RAG projects for better data analytics*

---

## LLM이란 무엇인가?

IBM에서는 LLM을 이렇게 정의합니다:

> “대규모 텍스트 데이터를 학습해 인간처럼 언어를 이해·생성할 수 있는 모델.”  
> *(참조: IBM – Large Language Models)*

HPE에서는 이런 표현도 있습니다:

> “LLM은 단순한 언어 생성 모델을 넘어, 검색·요약·추론·질문응답 같은 고차원 작업을 수행하는 범용 언어 엔진.”  
> *(참조: HPE – What is a Large Language Model?)*

즉, LLM은 **언어를 기반으로 한 지능형 인터페이스이자,  
데이터 해석·탐색·추론까지 가능한 새로운 형태의 도구**입니다.

---

## LLM이 데이터 분석가와 무슨 관계가 있을까?

이전엔 분석가가 다루던 도구가  
SQL → Python → 시각화 도구 수준이었다면,  

이제는 **LLM이 분석 프로세스 자체를 바꿔놓고 있습니다.**  

특히 InfoWorld에서 강조한 것처럼,  
LLM을 데이터 분석과 결합한 **RAG(Retrieval-Augmented Generation)** 방식은  
잘못된 환각(hallucination)을 줄이면서  
정확한 분석·요약·검색을 가능하게 만드는 중요한 기법입니다.

---

## 제가 느낀 세 가지 포인트

### 1️⃣ LLM은 ‘검색 + 요약’이 아니라 새로운 분석 도구다  
처음엔 단순히 문장 잘 만드는 도구라고 생각했는데,  
이제는 자연어로 데이터를 탐색하고, 코드까지 생성하고,  
문제를 정의하는 데 도움을 주는 **분석 도우미** 역할을 할 수 있음을 알게 됐습니다.

특히 RAG는 내부 데이터 + LLM을 결합해  
“정확한 근거 기반 답변”을 만들면서,  
데이터 분석가가 매번 직접 쿼리하고 탐색하던 작업 일부를 자동화할 수 있게 합니다.

---

### 2️⃣ 데이터 분석가의 역할은 ‘도구 사용’이 아니라 ‘질문을 제대로 만드는 것’  
LLM 시대에는 도구 숙련도가 더 이상 경쟁력이 아니라고 느꼈습니다.  
중요한 건 **‘좋은 질문을 만드는 능력’**입니다.

- 어떤 문제를 해결하려는가  
- 어떤 데이터가 필요한가  
- 어떤 근거가 맞는지 검증할 수 있는가

LLM은 질문을 잘하면 훨씬 강력하게 답하고,  
질문을 잘못하면 엉뚱한 방향으로 데려갑니다.

즉, **분석가의 사고력**이 더 중요해진 시대입니다.

---

### 3️⃣ LLM이 잘하려면 결국 ‘정돈된 데이터’가 필요하다  
LLM을 아무리 붙여도,  
정작 조직 내 데이터가 정리되어 있지 않으면 제대로 작동하지 않습니다.

- 정제되지 않은 로그  
- 일관성 없는 스키마  
- 설명이 없는 데이터 컬럼  
- 중복/누락된 값

이런 상태에서는 RAG든 앵커링이든 전혀 효과가 없습니다.

결국 LLM 시대에도  
데이터 분석가의 **정제·정리·문서화·해석 능력**은 더 중요해졌습니다.  
도구는 바뀌어도 “Garbage In, Garbage Out”은 그대로니까요.

---

## 앞으로의 목표 ✨

저는 LLM을 단순히 “새로운 기술”로 보지 않고,  
**분석가의 사고력을 확장시키는 도구**로 보고 싶습니다.

- 데이터 기반 질문을 더 잘 만들고  
- 문제 정의를 명확히 하고  
- LLM과 RAG를 활용해  
  분석의 생산성과 깊이를 확장시키는 분석가  

이 방향으로 성장하고 싶습니다.
